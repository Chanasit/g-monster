# Creature silhouettes. One 24x24 block per species, keyed by the species key in
# resources/data/creatures.json.
#
#   '#' = ink (opaque black)    '.' = clear (fully transparent)
#
# Only this frame is authored. tools/sprites/generate_sprites.py emits it as
# <key>_0.png and derives <key>_1.png by shifting the whole grid down one row --
# that one-row drop is the idle "breath" the battle and party screens animate.
# Row 23 must therefore stay blank, or the shift would clip the sprite's feet.
#
# Shapes are bilaterally symmetric and drawn in chunky 2px-ish strokes so they
# stay legible after the 3x upscale to 72x72 on a 240px watch face.
#
# Edit the ASCII, rerun the generator, rebuild. Do not hand-edit the PNGs.
